## 🚀 How to Run

Make sure Python is installed on your computer.

Check your Python version:

```bash
python --version
```

Clone the repository:

```bash
git clone https://github.com/your-username/python-learning.git
```

Move into the project folder:

```bash
cd python-learning
```

Run a Python file:

```bash
python filename.py
```
